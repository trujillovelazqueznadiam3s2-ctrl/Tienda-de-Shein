### 📌 Descripción del proyecto

El sistema de gestión de tienda online es una plataforma diseñada para la administración de una tienda digital de ropa y accesorios, similar a SHEIN.  

Este proyecto consiste en el diseño y desarrollo de una base de datos relacional que permita:

- Gestionar productos (ropa, accesorios, etc.)  
- Administrar usuarios y clientes  
- Registrar pedidos y compras  
- Controlar inventario  
- Generar reportes de ventas y análisis de datos  

El sistema permitirá almacenar y organizar la información de manera estructurada, garantizando integridad, eficiencia y escalabilidad.

---

### 🎯 Objetivo general

Diseñar e implementar una base de datos relacional que permita la gestión completa de una tienda en línea, asegurando la correcta organización, integridad y análisis de la información.

---

### 📌 Objetivos específicos

- Diseñar el modelo entidad-relación del sistema  
- Implementar tablas normalizadas (hasta 3FN)  
- Gestionar productos con diferentes categorías y tallas  
- Registrar usuarios y clientes  
- Administrar pedidos y métodos de pago  
- Desarrollar consultas para análisis de ventas  
- Integrar la base de datos con el sistema de aplicación  

---

### 💡 Justificación

Muchas tiendas en línea requieren sistemas eficientes para gestionar grandes cantidades de productos y usuarios. Este sistema permitirá:

- Administrar productos de forma organizada  
- Centralizar la información de clientes y pedidos  
- Obtener reportes rápidos de ventas  
- Mejorar la toma de decisiones basada en datos
